Destination

1 · In-app Tuning panel

Every audio / turn-taking / segmentation / denoise / transcript-check knob and curated model pickers, per mode, in a collapsible panel. Applied at session start and live mid-session. Presets, JSON export/import, localStorage.

2 · New processing stages

Client: RMS noise gate, RNNoise-WASM. Realtime: OpenAI near/far noise reduction. Cascade: DeepFilterNet server denoise, LLM transcript check (off / flag / correct). Offline: Demucs/denoiser, noisereduce.

3 · Benchmark that answers "did it help?"

Noisy corpus (synthetic babble/street/fan at 3 SNRs + your real recordings) run through every config, reporting WER, judge score and added latency per config fingerprint. Same TuningConfig JSON drives the app and the harness.

Risks & constraints carried forward

Realtime client DSP needs a re-plumbed track
Today the raw mic track goes straight into RTCPeerConnection. RMS gate / RNNoise require mic → AudioContext → worklet → MediaStreamDestination → WebRTC. Echo/gain constraint semantics may change subtly.
Live-apply on Cascade means Deepgram reconnects
endpointing/utterance_end_ms/model are connection params. Changing them mid-session must reconnect without losing in-flight segments; latency records should note the reconnect.
Torch is heavy
DeepFilterNet/Demucs pull PyTorch. Extras group + runtime detection keeps CI light, but the "greyed out" state must be tested.
Clean corpus can't show gains
Existing WER ≈ 0 on TTS audio. All denoise claims must come from the noisy variants; the report must show the clean baseline too so regressions are visible.
correct mode can hurt
An LLM rewriting ASR output may "fix" correct text. Raw-vs-corrected WER per segment is the guard; flag is the safe default.
Wave-U-Net may be dropped
No maintained pip package known; if none is found during research it is replaced by Demucs/denoiser + noisereduce without a new gate.

Non-goals (confirmed)

  • No server-side / account storage of presets — localStorage + JSON files only
  • No GPU requirement or GPU-specific code paths
  • No Demucs / Wave-U-Net in the live path
  • No correct mode in Realtime (no seam) — flag only
  • No per-device mic calibration wizard
  • No new language pairs — EN↔ES/FR stays
  • Real noisy recordings are supplied by you; harness self-skips that set when absent
