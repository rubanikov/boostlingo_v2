TuningConfig (schemaVersion 1) & fingerprint

Shape

TuningConfig {
  schemaVersion: 1
  client:   { microphone{EC,NS,AGC}, rmsGate{enabled,thresholdDbfs,holdMs,
              attackMs,releaseMs,attenuationDb,fullMute}, rnnoise{enabled,voiceProbThreshold} }
  realtime: { model, voice, turnDetection{type, threshold?, prefixPaddingMs?,
              silenceDurationMs?, eagerness?, interruptResponse?},
              noiseReduction?: off|near_field|far_field,
              transcriptCheck{mode: off|flag, model} }
  cascade:  { deepgram{model,endpointingMs,utteranceEndMs,diarize}   ← connection-level
              segmentation{mode,model},
              denoise{noisereduce{…}, deepfilternet{…}, offline{demucs,dns64}},
              transcriptCheck{mode: off|flag|correct, model},
              translationModel, ttsVoiceA, ttsVoiceB }
}
// wire + hash document = projectMode(config, mode)  (mode is inside the hash)

Absent = provider default only for the OpenAI pass-through fields; everything else is required-with-default. noiseReduction is three-state + absent (absent → no key; off → null).

Fingerprint (byte-exact in TS and Python)

  1. project to mode (includes schemaVersion + mode)
  2. strip undefined/None keys (keep false/0/"")
  3. clamp + quantise floats to documented step
  4. canonical JSON: sorted keys, no whitespace, integral floats as ints
  5. SHA-256 → first 8 hex → cfg:xxxxxxxx

Parity enforced by one committed fixture shared/tuning-fingerprint-cases.json read by both test suites. localStorage keys boostlingo.tuning.v1 / boostlingo.tuning.presets.v1, versioned, discarded on mismatch.

Deliberate Deepgram reconnect — no frame lost

sequenceDiagram
  participant C as Client
  participant P as _pump_client_messages
  participant Q as audio_queue (FIFO)
  participant S as _run_stt / audio_iter
  participant D as Deepgram
  C->>P: frames A,B
  P->>Q: A, B
  C->>P: update_tuning (connection-level)
  P->>Q: _RECONNECT sentinel (behind A,B)
  C->>P: frames C,D
  P->>Q: C, D
  S->>D: A, B (stream #1)
  S-->>S: pops _RECONNECT → audio_iter returns
  D-->>S: flush + close → StopAsyncIteration
  S-->>S: pending? cut partial buffer (trigger=tuning_reconnect), swap current/previous
  S->>D: stream #2 with new DeepgramParams
  S->>D: C, D (still in queue)
  D-->>S: first result
  S-->>C: tuning_applied{reconnectedStt:true}

Coalescing: a second update_tuning before the reconnect completes overwrites the single pending slot; a fresh sentinel is only enqueued if none was pending. Failure: each attempt logs + sends tuning_failed; after the existing 3-attempt/0.5-1-2 s budget the server reverts to previous params and the client shows the alert dialog (Retry / Revert). Client-side, Apply during TTS playback / a Realtime reply is held in one pendingTuningRef slot and flushed at the turn boundary.

Capture graphs

Cascade: micSource → [gate] → [rnnoise] → pcm worklet → destination; context at 48 kHz only when RNNoise is on, worklet decimates 3:1 back to 16 kHz.

Realtime: raw track unchanged when no client stage is on; else ctx(48k) → [gate] → [rnnoise] → MediaStreamDestination and addTrack(sentTrack); mute logic targets the sent track (the regression most likely to slip).

RNNoise: @sapphi-red/web-noise-suppressor (ships a worklet with the 480-sample/48 kHz framing; Vite ?url for wasm + worklet).

New dependencies & flags

torch + deepfilternet → backend[denoise] extra
CPU wheel index pinned via [[tool.uv.index]]; uv sync --extra denoise; core CI torch-free. First optional-dependencies section in the repo.
noisereduce + numpy → backend[bench] extra
Decision: extra, not main deps (pulls scipy/numba). Consequence: shows "not installed" in a default install. Open question 1.
@sapphi-red/web-noise-suppressor (frontend runtime dep)
First runtime dep since React. Verify ?url-loaded worklet under both vite dev and vite build before building on it.
No new scheduler / DB / datastore
Reconnect reuses _run_stt's outer loop + with_reconnect budget; apply queue is one ref slot; persistence is localStorage.
Security-relevant default widened
cors_origins default gains http://localhost:5183 (Playwright port) so the WS origin guard admits the harness. Repo-owned dev port. Open question 4.
Sharpest edge
Deepgram params must be per-stream() (DeepgramParams), never mutated module constants — otherwise one tab's Apply re-parameterises every session. Sentinel-in-queue design is deliberate; don't "simplify" to asyncio.wait.

Intentional deviations from approved artifacts

  1. transcriptCheck lives per mode (realtime: off/flag; cascade: off/flag/correct), not in the shared client block — type-exact, and a Cascade correct can't leak into a Realtime fingerprint. (Open question 2.)
  2. RMS gate is one shared gate-processor.js worklet for both modes; cascade-pcm-processor.js only gains the 48k→16k decimator.
  3. shared/tuning-fingerprint-cases.json introduces a new top-level dir (one file) for the cross-language parity fixture.
  4. Realtime flag needs the new POST /api/tuning/transcript-check endpoint. (Open question 5.)
  5. segment_boundary.trigger gains tuning_reconnect (additive-safe; label "reconfig").

Open questions (with recommendations)

Q1 · noisereduce+numpy: bench extra or main deps?

Recommendation: keep them in the bench extra as specified — default uv sync stays fast; the panel's "not installed" hint tells you exactly what to run.

Q2 · transcriptCheck per mode (deviation 1)?

Recommendation: confirm per-mode — it is the only type-exact shape.

Q3 · ElevenLabs voice picker: only the two configured ids + ELEVENLABS_VOICE_IDS_EXTRA, or a curated premade list?

Recommendation: two configured + env extra list, as specified — premade ids differ per account and can't be verified offline.

Q4 · Widen cors_origins default to include 5183?

Recommendation: yes — repo-owned dev port, documented in .env.example; simpler than every harness invocation setting CORS_ORIGINS.

Q5 · Realtime flag via the extra POST /api/tuning/transcript-check round trip: keep or drop?

Recommendation: keep — it's tier 4, best-effort and non-blocking, and it's the only way Realtime gets any transcript-quality signal at all.
